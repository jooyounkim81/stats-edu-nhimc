# 통계를 모르는 내가 어떻게 논문을?

AI를 활용한 통계분석 및 연구방법 — 직원 대상 통계교육 실습 자료

> **합성데이터입니다.** 실제 환자 자료가 아니며, 결과는 임상 근거가 아닙니다.
> 실제 환자 자료는 이 저장소나 어떤 AI에도 올리지 않습니다.

## 숙제: 직접 해 보고, 정답을 확인하세요

1. **자료 받기** — `data/appendicitis_synthetic.csv` 파일 하나만 내려받습니다.
2. **내가 쓰는 AI에 CSV만 올리기** — 이 저장소 전체를 AI에 연결하지 마세요. `answer_key/` 폴더에 정답이 있어서 AI가 그 파일을 읽고 답을 맞출 수 있습니다. 강의 준비 중에 실제로 그런 일이 있었습니다.
3. **지시문 넣기**
   - 파일을 올릴 수 있는 AI(대화창): `prompts/03_try-it-yourself.md`
   - 코드를 실행하는 AI(Claude Code 등): `prompts/04_analysis-steps.md`의 단계를 차례로
4. **검증하기** — AI의 답을 아래 10가지 질문으로 확인합니다. 틀린 곳이 나와도 열받거나 포기하지 말고, 다시 물어서 고치세요.
5. **정답 확인** — 다 한 뒤에 `answer_key/README.md`를 열어 내 결과와 비교합니다.

### AI 결과를 받으면 묻는 10가지

1. 대상자 수가 맞나? 빠진 사람과 이유를 밝혔나?
2. 결과변수 유형에 맞는 방법인가? (예/아니오, 일수)
3. 평균만 보고 있지 않나? 중앙값도 보았나?
4. 교란변수를 보정했나? 보정 전후 차이는?
5. 승산비를 "위험이 N배"처럼 말하지 않았나?
6. 하위군 차이를 상호작용 검정 없이 결론 내지 않았나?
7. 여러 번 검정한 것 중 p<0.05 하나만 강조하지 않았나?
8. "효과가 있다" 대신 "연관이 있다"로 썼나?
9. 글의 모든 숫자가 결과표와 같은가?
10. AI가 고쳤다고 한 내용이 실제로 실행한 파일에 들어 있는가?

## 폴더

| 경로 | 내용 |
|---|---|
| data/appendicitis_synthetic.csv | 급성 충수염 가상 환자 2,000명 (2016–2025, 연 200명) |
| prompts/ | 강의에서 AI에 넣은 지시문 |
| code/ | 내가 만든 코드를 저장하는 곳 (지시문이 이 폴더를 씀) |
| results/ | 내 결과 표와 그림이 저장되는 곳 |
| answer_key/ | **정답. 숙제를 끝낸 뒤에 여세요** |

## 변수

| 변수 | 뜻 |
|---|---|
| treatment | LA 복강경 수술, OA 개복 수술, NOM 비수술 항생제 치료 |
| age_group | <18, 18-64, >=65 |
| complicated | 복잡성 충수염(천공·농양) 1/0 |
| comorbidity | 동반질환 1/0 |
| los_days | 재원일수 |
| antibiotic_days | 항생제 투여일수 |
| analgesic_days | 진통제 사용일수 |
| complication | 합병증 1/0 |
| readmit_30d | 30일 내 재입원 1/0 |
| failure_1y | 1년 내 치료실패 1/0 |

자료에는 연습용 입력 오류가 일부러 들어 있습니다. 몇 건인지는 직접 찾아보세요.
