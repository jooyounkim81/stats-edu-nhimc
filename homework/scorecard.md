# 채점표 — 내 AI의 답 확인하기

AI에서 답을 받은 뒤, 정답을 보기 **전에** 이 표를 채우세요. 이 파일을 내려받아 메모장이나 워드에 붙여 써도 됩니다.
판정은 세 가지 중 하나로 적습니다.

- **맞힘**: AI가 짚어야 할 것을 짚었다
- **놓침**: 짚지 않았다
- **과장**: 근거보다 세게 말했다 (예: 인과로 단정, 우연한 결과를 효과로 해석)

| 번호 | 항목 | 확인할 것 | 내 AI의 답 (숫자·한 줄 요약) | 판정 |
|---|---|---|---|---|
| T1 | 재원일수 | 평균만 보지 않고 중앙값을 보았나? 분포 모양을 짚었나? | | |
| T2 | 항생제 투여일수 | 비수술군이 긴 이유를 설명했나? | | |
| T3 | 진통제 사용일수 | 개복과 복강경의 차이를 다른 요인을 고려한 뒤에도 확인했나? | | |
| T4 | 합병증 | 보정 전후 승산비가 왜 다른지 설명했나? 인과로 단정하지 않았나? | | |
| T5 | 30일 재입원 | 유의하지 않은 결과를 "효과 없음"으로 단정하지 않았나? | | |
| T6 | 1년 치료실패 | 군마다 "실패"의 뜻이 같은지 물었나? 승산비와 위험비를 구분했나? | | |
| T7 | 연령 하위군 | 상호작용 검정으로 판단했나? | | |
| T8 | 성별 | 우연히 나온 p<0.05를 효과로 과장하지 않았나? | | |
| T9 | 연도 추세 | 치료법 변화와 시대 변화를 나눠 보았나? | | |
| T10 | 입력 오류 | 분석 전에 이상한 값을 찾았나? 몇 건이었나? | | |

다 채운 뒤 `answer_key/README.md`의 정답표와 비교하세요.
