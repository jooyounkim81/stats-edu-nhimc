# 연구계획서 요청 (Claude, GPT 공통)

급성 충수염 환자의 치료방법(복강경 수술, 개복 수술, 비수술 항생제 치료)에 따른 단기 결과를 비교하는 후향적 코호트 연구의 연구계획서 초안을 써 줘.

PICO
- 대상: 2016–2025년 급성 충수염으로 입원한 환자
- 노출: 개복 수술 / 비교: 복강경 수술
- 결과: 1차 합병증, 2차 재원일수·항생제 투여기간·진통제 사용일수·30일 재입원·1년 치료실패
- 하위군: 연령(18세 미만, 18–64세, 65세 이상), 성별

조건
- 결과변수마다 자료에서 어떻게 셀지 정의해 줘.
- 교란변수 후보와 이유를 적어 줘.
- 문헌을 인용할 때는 실제로 존재하는지 확인할 수 있게 제목과 연도를 적고, 확실하지 않으면 "확인 필요"라고 써 줘.
