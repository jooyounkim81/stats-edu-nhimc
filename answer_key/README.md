# 정답 폴더 — 숙제를 끝낸 뒤 여세요

> **합성데이터입니다.** 실제 환자 자료가 아니며, 결과는 임상 근거가 아닙니다.

이 폴더에는 자료를 만든 코드(심어 둔 정답이 들어 있음)와, 강의 준비 중 Claude Code가 실제로 만든 분석 코드와 결과가 들어 있습니다.
먼저 저장소 맨 위 README의 순서대로 직접 해 보고, 그다음에 열어 보세요.

## 폴더

| 경로 | 내용 |
|---|---|
| generate/01_generate.py | 합성데이터를 만든 코드. 아래 정답표의 "심어 둔 정답"이 코드에 들어 있음 |
| generate/02_analysis.py | 정답 확인용 분석 (시드 12개) |
| generate/results.json | 02_analysis.py 실행 결과 |
| lecture/code/ | 강의 준비 중 Claude Code가 작성한 코드 (Table 1, Table 2, 재원일수 분포, 합병증, 하위군, 연도 추세) |
| lecture/results/ | 위 코드의 결과 표와 그림 |

## 정답표 (시드 20261103)

| 번호 | 항목 | 심어 둔 정답 (설계) | 이 자료에서 나온 값 | AI가 짚어야 할 것 |
|---|---|---|---|---|
| T1 | 재원일수 | 개복 +2일, 비수술 +1일, 복잡성 +3일, 65세 이상 +1.5일, 동반질환 +1일. 오른쪽으로 치우친 분포, 약 1%는 장기 입원 | 중앙값 복강경 3일, 개복 6일, 비수술 4일 (평균 3.9 / 7.3 / 4.7일). 왜도 4.53, 30일 이상 10명 | 평균보다 중앙값. 치우친 자료에 맞는 방법 (순위 비교, 로그 변환, 음이항 회귀 등) |
| T2 | 항생제 투여일수 | 단순 충수염 수술 1~2일, 복잡성 5~7일, 비수술 7~10일 | 중앙값 복강경 2일, 개복 2일, 비수술 9일 | 비수술군이 긴 것은 치료 설계상 당연함 |
| T3 | 진통제 사용일수 | 개복 +1.5일 (복잡성 +1일) | 중앙값 복강경 2일, 개복 4일, 비수술 2일 | 보정해도 개복이 김 |
| T4 | 합병증 | 승산비: 개복 1.5 (65세 미만) / 2.5 (65세 이상), 복잡성 3.5, 65세 이상 1.8, 비수술 0.8 | 개복 보정 전 3.90 → 보정 후 2.34 (1.61–3.41). 복잡성 5.06, 65세 이상 2.47. 비수술 0.91 → 1.53 (0.78–2.98) | 보정 전후 차이를 교란(더 아픈 환자가 개복)으로 설명. 인과로 단정하지 않음 |
| T5 | 30일 재입원 | 승산비: 복잡성 2, 비수술 1.5 | 발생 5.1%. 복잡성 2.14 (1.34–3.42), 비수술 1.52 (0.80–2.90, p=0.20) | 효과를 심어도 표본이 작으면 유의하지 않을 수 있음. "효과 없음"으로 단정하지 않음 |
| T6 | 1년 치료실패 | 비수술 25%, 수술 2% | 비수술 28.0%, 복강경 1.5%. 위험비 18.6, 승산비 25.4 | 군마다 "실패"의 뜻이 다름. 결과가 흔하면 승산비 ≠ 위험비 |
| T7 | 연령 하위군 | 65세 이상에서 개복 위험이 더 큼 (2.5 대 1.5) | 65세 미만 1.70, 65세 이상 2.75, 상호작용 p=0.19. 시드 12개에서 상호작용 p는 0.012~0.89로 흔들림 | 상호작용 검정 없이 "고령에서 더 위험"이라고 단정하지 않음 |
| T8 | 성별 | 효과를 넣지 않음 | 성별 상호작용 p=0.897. 성별 검정 18번 중 p<0.05는 0번 (다른 시드에서는 1~2번) | 우연히 나온 p<0.05를 효과로 과장하지 않음 |
| T9 | 연도 추세 | 재원일수 해마다 0.1일 감소 + 개복 비율 감소 | 연간 변화 보정 전 -4.5%, 보정 후 -3.2% | 감소의 일부는 치료법 변화, 나머지는 시대 변화 |
| T10 | 입력 오류 | 7건을 일부러 넣음 | 나이 150세 2건, 재원일수 음수 2건, 성별 빈칸 3건 → 분석 대상 1,993명 | 분석 전에 찾아서 보고 |

치료법 비율 (설계: 복강경 55→85%, 개복 35→5%, 비수술 10%): 2016년 55.5 / 36.0 / 8.5%, 2025년 84.9 / 5.0 / 10.1%

## 다시 실행해 확인하기

저장소 맨 위 폴더에서:

```
pip install -r requirements.txt
python answer_key/generate/01_generate.py 20261103 data/appendicitis_synthetic.csv
python answer_key/generate/02_analysis.py answer_key/generate/results.json
python answer_key/lecture/code/table2.py
```

lecture/code/의 코드는 결과를 저장소 맨 위 results/ 폴더에 새로 저장하므로, lecture/results/의 파일과 비교해 볼 수 있습니다.

실행 확인 환경: Python 3.13.18, numpy 2.5.3, pandas 3.0.5, scipy 1.18.1, statsmodels 0.15.0, matplotlib 3.11.2
